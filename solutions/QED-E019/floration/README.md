# QED-E019

The Lean proof uses a fixed block scale. Every block of length $2^k$ in $W_{k+r}$ agrees with $W_k$ up to its final letter. Uniformly strict angle structures permit transfers in both directions. A taper near the block boundaries preserves the angle constraints, and uniform continuity of the Lobachevsky function controls the volume change in the interior.

For any positive error tolerance, the boundary layer has a fixed width independent of $k$ and $r$. Taking $k$ large makes the normalized boundary loss small for every $r$. The normalized volumes are therefore Cauchy.
