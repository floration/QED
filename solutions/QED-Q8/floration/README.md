Galvin's induction on |s| (statement generalised to finsets, chains given by a colouring c : α → ℕ).
Remove a maximal a; in s \ {a} take, per colour, the top element lying in some maximum antichain;
these form a maximum antichain X. If no x ∈ X is below a, X ∪ {a} works with a new colour; otherwise
remove the chain K = {a} ∪ {z of x's colour, z ≤ x}: the rest has width < k, so K plus its cover gives k chains.
