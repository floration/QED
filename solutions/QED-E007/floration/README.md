# QED-E007

Restrict to the surface sector with centered horizontal coordinates (Xge Y>0). Set the diagonal phases to (pi/4). For each off-diagonal vertex, holding its neighbors fixed gives a strictly decreasing force on ([0,pi/4]) with a unique zero. The zero is monotone in the neighbor phases, so the simultaneous update has a fixed point by Knaster–Tarski.

At an endpoint of the phase interval the force equation propagates that endpoint along the sector's grid paths. A path to the diagonal excludes zero, and a path to the reflecting boundary excludes (pi/4). Extend by quarter-turns and reflections. The resulting phase is an equilibrium, and rotational equivariance forces the two winding sums.

Every edge has nonnegative cosine weight, with strict positivity on the grid after the two central plaquette boundaries are removed. The remaining graph is connected, so the quadratic form is strictly positive on nonconstant surface vectors.
