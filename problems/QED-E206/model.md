# QED-E206 — Is strong shift equivalence of nonnegative integer matrices decidable?

You are an AI model helping someone attack this open problem. Read all of this before working.

## The problem
Extended set · Grade A · QED Curated · Dynamics

**Plain words:** Call two square matrices A and B with nonnegative integer entries elementarily equivalent if A = RS and B = SR for some rectangular nonnegative integer matrices R and S, and strongly shift equivalent if they are linked by a finite chain of such moves. By Williams' 1973 theorem this is exactly when two shifts of finite type are topologically conjugate. Is there an algorithm that decides, given A and B, whether they are strongly shift equivalent?

**Math:** For $A\in\mathbb Z_{\ge0}^{m\times m}$, $B\in\mathbb Z_{\ge0}^{n\times n}$ with $m,n\ge1$ write $A\approx B$ if there are $R\in\mathbb Z_{\ge0}^{m\times n}$, $S\in\mathbb Z_{\ge0}^{n\times m}$ with $A=RS$, $B=SR$; let $\sim_{SSE}$ be the equivalence relation generated by $\approx$ on square matrices of all positive sizes. Determine whether $\{(A,B):A\sim_{SSE}B\}$ is a computable set (it is computably enumerable).

**Credit:** Problem implicit in R. F. Williams, Annals of Math. 98 (1973); stated as the main open problem in Boyle's symbolic dynamics open-problem list and in Lind-Marcus, 'An Introduction to Symbolic Dynamics and Coding'.

**Rests on recent unrefereed work. Check these premises first:**
- Recent status relies partly on unrefereed 2026 preprints (Jeandel 2609.03567, Bilich et al. 2609.11834), but all only confirm openness
- Must be stated for SSE over Z_+ (over Z, SSE=SE and is decidable for some cases); stating it over Z would be a different problem
